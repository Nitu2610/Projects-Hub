# Full-Stack Projects Hub

A collection of full-stack web development projects built to strengthen practical skills across frontend development, backend engineering, REST API design, authentication, database management, business logic, and deployment.

The projects progress from a frontend-focused e-commerce implementation to full-stack applications with authentication, role-based access control, business workflows, and production-style architecture.

### 02 — Customer Support Ticket Management System

A full-stack customer support platform designed to manage support tickets across different user roles.

The application provides separate workflows for customers, support agents, and administrators, including ticket creation, assignment, status management, searching, filtering, sorting, and pagination.

#### Key Features

- Customer, Agent, and Admin roles
- JWT-based authentication
- Protected routes
- Ticket creation and management
- Ticket search and filtering
- Sorting and pagination
- Role-based workflows
- REST API integration
- MongoDB-based data persistence
- Dashboard and data visualization

#### Tech Stack

**Frontend**

`React` · `Vite` · `React Router` · `Chakra UI` · `Axios` · `Context API` · `Custom React Hooks` · `Recharts`

**Backend**

`Node.js` · `Express.js` · `MongoDB` · `Mongoose` · `JWT` · `bcrypt` · `express-validator` · `Morgan` · `CORS` · `dotenv`

#### Links

### 03 — TechNest — Full-Stack E-commerce & Order Management Platform

A full-stack e-commerce and order management platform built with React, TypeScript, Node.js, Express, and MongoDB.

TechNest includes separate customer and administrator workflows covering product management, categories, cart, checkout, orders, reviews, inventory, and administrative operations.

The project follows a layered backend architecture and focuses heavily on implementing business rules and handling real-world application workflows.

#### Key Features

- Customer and Admin workflows
- JWT authentication using HTTP-only cookies
- Role-based access control
- Product and category management
- Hierarchical product categories
- Shopping cart
- Address management
- Checkout and order creation
- Payment workflow
- Order status management
- Customer and Admin order cancellation
- Inventory and stock management
- Product reviews
- Admin dashboard
- Revenue and order statistics
- Sales overview
- Inventory statistics
- REST API architecture
- Backend validation and business-rule enforcement

#### Backend Architecture

```text
Route
  ↓
Middleware
  ↓
Validation
  ↓
Controller
  ↓
Service
  ↓
Mongoose
  ↓
MongoDB
```

#### Tech Stack

**Frontend**

`React` · `TypeScript` · `Vite` · `Redux Toolkit` · `RTK Query` · `React Router` · `Chakra UI`

**Backend**

`Node.js` · `Express.js` · `TypeScript` · `MongoDB` · `Mongoose` · `JWT` · `HTTP-only Cookies` · `Express Validator` · `bcrypt`

**Supporting Services**

`Cloudinary` · `MongoDB Atlas`

#### Deployment

- **Frontend:** Vercel
- **Backend:** Railway
- **Database:** MongoDB Atlas
- **Product Images:** Cloudinary

#### Links

# 🏗️ Development Approach

The projects were developed with an emphasis on understanding the complete application development lifecycle rather than only implementing UI features.

```text
Requirements
     ↓
Business Rules
     ↓
Architecture
     ↓
Database Design
     ↓
API Design
     ↓
Implementation
     ↓
Validation
     ↓
Testing & Debugging
     ↓
Deployment
     ↓
Documentation
```

For the full-stack projects, particular attention was given to keeping important business rules on the backend and maintaining clear separation between routes, controllers, services, and database models.
